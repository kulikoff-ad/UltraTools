# UltraTools 🏝️

**UltraTools** — iOS-приложение на SwiftUI: конструктор собственного «островка» (Dynamic Island) и набор скрытых настроек iOS в духе классических модов — с живым предпросмотром на макете iPhone.

---

## ✨ Возможности

### 🏝️ Конструктор островка
- **4 формы**: Капсула, Пилл, Круглый, Сквиркл
- **6 видов содержимого**: Пустой, Музыка, Таймер, Звонок, Камера, Зарядка
- **8 цветов** + режим градиента
- **Пульсация** — островок мягко «дышит»
- **Размер** от 80% до 130%
- **Живой предпросмотр** на макете iPhone с настоящим статус-баром
- **Пресеты** — сохраняйте свои конфигурации и переключайтесь между ними
- **Экспорт в PNG** — скачайте или поделитесь своим островком

### 🎛 Скрытые настройки (14 штук)
В 4 группах: **Экран**, **Батарея**, **Звук и тактильность**, **Система**.

Несколько настроек реально влияют на живой предпросмотр:
- Процент заряда на статус-баре
- Секунды в часах
- Название оператора
- Скрыть Dock
- Ночной режим / адаптивная яркость / сверхэкономия
- Низкий заряд с предупреждением
- Режим разработчика и счётчик FPS
- Тактильные отклики (вибрация при переключении тумблеров)

## 🚀 Сборка приложения в Xcode

1. Откройте `UltraTools.xcodeproj` в Xcode.
2. В **Signing & Capabilities** укажите свой **Team** (бесплатный Apple ID подходит для установки на своё устройство).
3. Выберите устройство или симулятор и нажмите **Run**.

## 📱 Сборка .ipa

Готовый `build/UltraTools.ipa` собирается одной командой (только macOS + Xcode):

```bash
./build_ipa.sh
```

Варианты подписи:

```bash
./build_ipa.sh developer-id   # по умолчанию: подпись Developer ID
./build_ipa.sh ad-hoc         # ad-hoc: установка на свои устройства
./build_ipa.sh app-store      # подготовка к публикации в App Store
```

Указать команду Apple (10-значный ID):

```bash
TEAM_ID=ABCDE12345 ./build_ipa.sh
```

> Для **ad-hoc** и **app-store** нужен аккаунт Apple Developer ($99/год) и
> provisioning-профиль; для **developer-id** — сертификат Developer ID,
> созданный в Keychain Access.

### Как установить .ipa на iPhone

- **AltStore** или **Sideloadly** — перетащите файл `.ipa`, приложение установится по Wi-Fi.
- **TrollStore** (устройства с подходящей версией iOS) — просто откройте файл.
- **TestFlight** — если вы публикуете через App Store.

## 🌐 Веб-демо интерфейса

Папка `web/` содержит интерактивную веб-реплику интерфейса — её можно открыть
прямо в браузере (без сборки Xcode):

```bash
cd web
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Там же работает конструктор островка, все 14 настроек (влияют на живой макет
телефона) и экспорт островка в PNG.

## ⚠️ Важно (честно о возможностях)

- **Скрытые настройки — имитация.** Ни одно приложение App Store не может
  менять реальные системные настройки iOS без джейлбрейка (API для этого не
  существует). В UltraTools настройки управляют живым предпросмотром внутри
  приложения — так можно экспериментировать с дизайном и визуализировать
  «как это выглядело бы».
- **Островок — визуальный элемент приложения.** Настоящий Dynamic Island
  существует только на системном уровне (Face ID), приложения могут лишь
  отображать свою активность в нём. UltraTools создаёт собственный островок
  на макете iPhone и умеет экспортировать его в PNG.
